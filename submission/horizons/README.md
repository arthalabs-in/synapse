# Horizons notes

These notes summarize rules relevant to SYNAPSE. Confirm current status on the
logged-in Horizons site before submitting.

## Qualification

- Nexus requires 30 approved hours; other Horizons events require 35.
- Existing projects are allowed, but only work logged after February 22, 2026
  counts.
- Software time is tracked through Hackatime.
- A project must be open source and usable as a demo when shipped.
- Reviewers approve hours; tracked time alone is not approved time.

## Project requirements

- Public repository: `https://github.com/arthalabs-in/synapse`
- Public demo: deploy `frontend/app.py` and add the URL to the project.
- Use the submitter's own project description and updates.
- Do not use generated graphics or audio in the submission.
- Confirm that the project was not submitted to another Hack Club program that
  prohibits double-dipping. Sleepover is the stated exception in the public FAQ.

## Before opening the Ship Wizard

1. Link the correct Hackatime project.
2. Check that logged hours fall after the cutoff.
3. Verify the repository, README, and demo URLs in a private browser window.
4. Confirm identity and mailing details in Hack Club Auth.
5. Complete `ship_checklist.md`.

Questions about eligibility, timing, or previous program submissions should go
to `horizons@hackclub.com` or the current Horizons help channel in Slack.
