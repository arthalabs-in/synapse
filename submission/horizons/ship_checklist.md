# Horizons ship checklist

## Repository

- [ ] `https://github.com/arthalabs-in/synapse` is public.
- [ ] The branch being submitted contains the current README and UI.
- [ ] `.env`, secrets, local caches, and generated artifacts are not tracked.
- [ ] `python -m pytest` passes on the submitted revision.

## Demo

- [ ] A public Streamlit URL is available.
- [ ] `DEMO_MODE=true` and the checked fixture loads.
- [ ] The URL works in a private browser window without authentication.
- [ ] The query, report, evidence, fact status, patch details, and export are usable.

## Hours

- [ ] The correct Hackatime project is linked.
- [ ] Counted work was logged after February 22, 2026.
- [ ] The project has enough eligible time for the selected event.
- [ ] The platform shows the hours as approved after review.

## Account

- [ ] Hack Club Auth onboarding is complete.
- [ ] Age/identity verification is current.
- [ ] Mailing address is present.
- [ ] The selected event is still available in the logged-in Events page.

## Submission integrity

- [ ] The project description and updates were written by the submitter.
- [ ] Graphics and audio comply with the current generative-media rule.
- [ ] Previous Hack Club submissions do not violate the double-dipping rule.
- [ ] Repository, README, and demo URLs resolve from outside the local network.

If any rule is unclear, confirm it with `horizons@hackclub.com` before shipping.
