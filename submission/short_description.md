# Short description notes

Write the platform description yourself. Useful facts to cover:

- SYNAPSE researches a question using public sources.
- It preserves the quoted passage supporting each accepted claim.
- A fact ledger separates verified, partial, unsupported, and contradicted claims.
- The interface shows evidence, claim status, coverage edits, and run warnings.

Avoid claims that the system eliminates hallucinations or proves that every
answer is true.
