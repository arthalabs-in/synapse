# Submission Brief

## Project

**SYNAPSE** - Answers you can audit.

## Category Fit

- Artificial Intelligence & Machine Learning
- Education Technology
- Startup & Productivity Solutions
- Open Innovation

## Core Claim

SYNAPSE makes AI research trustworthy by requiring every accepted answer to
trace back to source quotes, fact IDs, validator checks, and patch operations.

## What To Show Judges

1. Ask a hard research question.
2. Show searched and fetched sources.
3. Show evidence cards with real quotes.
4. Show the fact ledger: verified, partial, unsupported, contradictions.
5. Show the final answer with fact IDs.
6. Show patch diff metadata: edit reason, location, before, after.
7. Run `validate_live_golden.py` and show it passing.

## Competitive Angle

Many hackathon AI apps are chatbot wrappers. SYNAPSE is a research verification
pipeline. The value is not just the answer; it is the audit trail proving how
the answer was produced.

## Proof Points

- Full test suite passes.
- Live golden artifacts validate.
- Demo mode works without live network access.
- UI-ready patch operations are present in validated artifacts.
- Provider metrics and run quality are included in every run.
